# From Gene to Medicine

**Retracing a cancer drug's discovery with AlphaFold and free genomics tools**
CAYHIC 2026 · 28 September 2026 · Ulugbek Baymuradov, computational biologist

We follow one real medicine: the HER2 gene → the drug trastuzumab (Herceptin) → the next-generation drug Enhertu. At each step we look at the free tools and data anyone can use, and at how computers now help.

## Follow HER2 yourself

| Tool | Try this |
|---|---|
| [Global Cancer Observatory](https://gco.iarc.who.int) | Fact sheets → your country |
| [cBioPortal](https://www.cbioportal.org) | Breast Invasive Carcinoma (TCGA, PanCancer Atlas) → gene ERBB2 → Submit |
| [UniProt](https://www.uniprot.org/uniprotkb/P04626) | HER2's ID card: P04626 |
| [AlphaFold DB](https://alphafold.ebi.ac.uk/entry/P04626) | Predicted 3D shape of HER2 |
| [RCSB PDB](https://www.rcsb.org/structure/1N8Z) | 1N8Z: trastuzumab gripping HER2 → 3D View |
| [DepMap](https://depmap.org/portal/) | Search ERBB2: which cancer cells need it |
| [ClinicalTrials.gov](https://clinicaltrials.gov) | Intervention "trastuzumab" → filter by country |
